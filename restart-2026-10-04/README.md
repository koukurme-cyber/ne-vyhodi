# НЕ ВЫХОДИ — restart 2026-10-04

Чистый первый vertical slice игры про Бродского. Старый код и ассеты не используются.

Сейчас реализовано:
- один экран ленинградского двора;
- управление с клавиатуры и сенсорные кнопки;
- рисованный персонаж Бродского вместо геометрического placeholder;
- патрулирующий NPC с накоплением обнаружения, погоней и поиском после потери игрока;
- два укрытия;
- проигрыш при начале разговора;
- выход через арку как конец первого фрагмента.

Запуск: открыть `index.html` или поднять любой статический HTTP-сервер.
