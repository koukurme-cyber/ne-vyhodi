# Не выходи — три эпизода

Статическая браузерная игра: двор → проходной двор → улица.

Управление: A/D или стрелки, Shift — быстрее, E — спрятаться/выйти. На телефоне — экранные кнопки. Кнопка «Дальше» продолжает прохождение, вкладки открывают любой уровень для тестирования. После проигрыша повторяется текущий уровень.

Соседки окликают Бродского при обнаружении. Оклик ещё не означает проигрыш: можно убежать и спрятаться. Разговор начинается при контакте.

Запуск: `python -m http.server 8080 --directory restart-2026-10-04` из корня репозитория. Проверка логики: `node restart-2026-10-04/tests/verify-game.cjs`.

Графика в assets/: courtyard.png, passage.png, street.png, characters.png. Новые фоны созданы встроенным Imagegen по стилю первого двора: плоский маршрут, тёмные подъезды, снег, окна и арка. Спрайты героев общие для эпизодов.
